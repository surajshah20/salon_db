# Salon Appointment Booking System

A full-stack web application built for a salon to manage services, create customer appointments, and track booking statuses.

## Tech Stack
* **Frontend:** React.js (via Vite)
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL

## Prerequisites
Before running the project, ensure you have the following installed:
* Node.js
* PostgreSQL

## Setup Instructions

### 1. Database Setup
1. Open your PostgreSQL terminal (psql) or pgAdmin.
2. Create a new database called `salon_db`:
   ```sql
